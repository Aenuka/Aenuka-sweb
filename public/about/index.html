About Aenuka Buddhakorala

Software engineering undergraduate, web developer, and collaborative builder focused on turning continuous learning into practical software.

My software engineering journey

My interest in web development began after my O/L examinations, when I started learning HTML through tutorials and building small web applications. Seeing ideas become working interfaces led me to pursue software engineering more seriously.

I completed a Certificate Course in Computer Science at NIBM alongside an Advanced English course, developing both technical confidence and communication skills. I am currently a third-year Software Engineering undergraduate at the Sri Lanka Institute of Information Technology (SLIIT).

How I work

I enjoy learning through real projects, working with teams, and taking responsibility for planning and delivery. My academic projects have given me experience with Agile practices, repository management, system design, full-stack development, automated testing, and distributed systems.

Professional interests

  • Full-stack web application development
  • Java and Spring Boot backend systems
  • React, Node.js, Express, and modern JavaScript
  • Cloud-native development with Docker and Kubernetes
  • Software quality assurance and Cypress automation
